# 🛒 Shopping With Shivansh

A responsive Ecommerce Website built using HTML, CSS, and JavaScript. Users can browse products, search items, filter by categories, sort products, manage cart items, and experience a complete shopping workflow.

## Features

- Product listing with images and descriptions
- Search products instantly
- Category-based filtering
- Product sorting
  - Price: Low to High
  - Price: High to Low
  - Name: A-Z
  - Name: Z-A
- Add to Cart functionality
- Cart quantity management
- Remove items from cart
- Real-time cart count
- Checkout system
- Fake order generation
  - Order ID
  - Estimated Delivery Date
  - Payment Method
- Toast notifications
- Dark Mode support
- LocalStorage data persistence
- Fully Responsive Design

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage API
